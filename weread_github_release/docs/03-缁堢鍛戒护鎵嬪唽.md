## 环境（首次）

```bash
python3 -m venv AIAgent_algorithm
source AIAgent_algorithm/bin/activate
pip install -r requirements.txt
chmod +x pipeline.sh
cp config.example.json config.json   # 若尚无 config.json
```

## 日常

```bash
./pipeline.sh login          # 扫码
./pipeline.sh bootstrap      # 初始化
./pipeline.sh daily          # 增量
./pipeline.sh paths
./pipeline.sh install-cron   # 每天 17:00（北京时间）
./pipeline.sh uninstall-cron
```

等价：

```bash
python wechat_crawler_weread.py login
python wechat_crawler_weread.py bootstrap
python wechat_crawler_weread.py daily --fresh
```
