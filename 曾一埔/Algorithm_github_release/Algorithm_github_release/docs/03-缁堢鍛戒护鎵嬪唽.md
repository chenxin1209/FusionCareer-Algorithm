# 终端命令手册（按步骤）

本文档汇总本项目**需要在终端执行的命令**。默认在项目根目录操作。

**项目根目录**（请按你的实际路径替换）：

```bash
cd "/Users/piupiu/Library/Mobile Documents/com~apple~CloudDocs/Research/AIAgent_algorithm"
```

以下命令均假设已 `cd` 到该目录。

---

## 步骤 0：进入项目目录（每次开新终端建议先执行）

```bash
cd "/Users/piupiu/Library/Mobile Documents/com~apple~CloudDocs/Research/AIAgent_algorithm"
```

---

## 步骤 1：首次环境准备（只需做一次）

### 1.1 创建 Python 虚拟环境

```bash
python3 -m venv AIAgent_algorithm
```

### 1.2 激活虚拟环境

```bash
source AIAgent_algorithm/bin/activate
```

激活成功后，终端提示符前会出现 `(AIAgent_algorithm)`。

### 1.3 安装 Python 依赖

```bash
pip install -r requirements.txt
```

### 1.4 安装 Playwright 浏览器（用于同步登录凭证，只需一次）

```bash
playwright install chromium
```

### 1.5 确认 urllib3 版本（避免 macOS SSL 报错）

```bash
python -c "import urllib3; print(urllib3.__version__)"
```

应显示 **1.26.x**（不要是 2.x）。若不是：

```bash
pip install "urllib3>=1.26.18,<2" "requests>=2.31.0,<3"
```

### 1.6 赋予 pipeline 脚本可执行权限（只需一次）

```bash
chmod +x pipeline.sh
```

## 步骤 2：确认公众号清单（`gzh.txt` + `公众号名字`）

爬虫只读取这两个文本文件作为**固定监测对象**：

| 文件 | 要求 |
|------|------|
| `gzh.txt` | 每行一个 fakeid（当前 60 行，可按需增减） |
| `公众号名字` | 每行一个名称，与 `gzh.txt` **行号一一对应** |

### 2.1 检查清单

```bash
wc -l gzh.txt 公众号名字
head -3 gzh.txt
head -3 公众号名字
```

两行数应相同。

### 2.2 新增或修改公众号

1. 在 `gzh.txt` 追加或修改一行 **fakeid**
2. 在 `公众号名字` **同一行号** 写上公众号名称
3. 保存后执行 `./pipeline.sh bootstrap` 或 `daily`

fakeid 获取方式见 [01-公众号fakeid获取.md](./01-公众号fakeid获取.md) §3.2。

## 步骤 3：同步微信公众平台登录凭证

凭证写入 **`config.json`** 的 `token` 与 `cookie`，**不会**修改 `gzh.txt` / `公众号名字`。

### 3.1 方案 A：内置浏览器（推荐）

```bash
./pipeline.sh sync-session
```

或：

```bash
source AIAgent_algorithm/bin/activate
python sync_wechat_session.py
```

**操作说明：**

1. 自动打开 Chromium，在窗口中登录 [微信公众平台](https://mp.weixin.qq.com/)
2. 打开后台首页（地址栏含 `token=数字`）
3. 回到终端按 **Enter**（若脚本在等待输入）
4. 看到「接口校验通过」即成功

登录态会写入 `.wechat_browser_profile/`（运行时生成，下次可能无需重登）。

### 3.2 方案 B：接管已打开的 Chrome（可选）

**① 用调试端口启动 Chrome（先完全退出 Chrome）：**

```bash
/Applications/Google\ Chrome.app/Contents/MacOS/Google\ Chrome \
  --remote-debugging-port=9222 \
  --user-data-dir="$HOME/.chrome-wechat-mp"
```

**② 在该 Chrome 中登录公众平台后台**

**③ 执行同步：**

```bash
./pipeline.sh sync-session --cdp http://127.0.0.1:9222
```

### 3.3 跳过接口校验（可选）

```bash
python sync_wechat_session.py --no-verify
```

## 步骤 4：首次爬取（每号最新 N 条，默认 10 条）

**前提：** 清单就绪（步骤 2）、凭证有效（步骤 3）。

查看当前输出目录配置：

```bash
./pipeline.sh paths
```

| 类型 | 配置项 | 默认示例 |
|------|--------|----------|
| 主存档 | `articles_base_dir` | `公众号文章/` |
| 当日增量（仅 daily） | `YYYYMMDD` + `daily_folder_suffix` | `20260517新增/` |

```bash
./pipeline.sh bootstrap
```

或：

```bash
source AIAgent_algorithm/bin/activate
python wechat_crawler.py.py bootstrap
```

**产出（运行后生成）：**

- `公众号文章/<公众号名>/` 下 Markdown
- `history.json`（供后续增量比对）
- 追加写入 `wx_poc.txt`

**耗时：** 60 个号约需较长时间，可用 `nohup`（见步骤 7）。

## 步骤 5：日常增量监测（手动执行）

```bash
./pipeline.sh daily
```

或：

```bash
source AIAgent_algorithm/bin/activate
python wechat_crawler.py.py daily
```

**产出：**

- 新文章写入 `公众号文章/`
- 当日目录 `YYYYMMDD新增/`
- 目录内 `新增统计.md`
- 追加 `daily_report.jsonl`
- 日志 `logs/daily_YYYYMMDD.log`

**查看统计：**

```bash
ls -d *新增
cat "$(ls -dt *新增 | head -1)/新增统计.md"
```

---

## 步骤 6：安装每天自动监测（北京时间 17:00）

```bash
./pipeline.sh install-cron
```

**确认：**

```bash
crontab -l
```

应看到含 `TZ=Asia/Shanghai` 和 `wechat_crawler.py.py daily` 的一行。

**定时日志：**

```bash
tail -50 logs/daily_cron.log
```

**移除：**

```bash
./pipeline.sh uninstall-cron
```

> Mac 休眠时 crontab 可能不执行；唤醒后可手动补跑 `./pipeline.sh daily`。

## 步骤 7：长时间后台运行（可选）

### 7.1 bootstrap 后台跑

```bash
mkdir -p logs
source AIAgent_algorithm/bin/activate
nohup python wechat_crawler.py.py bootstrap >> logs/bootstrap.log 2>&1 &
tail -f logs/bootstrap.log
```

### 7.2 中断

在运行爬虫的终端按：**Ctrl + C**

### 7.3 暂停后恢复（同一终端）

1. 暂停：**Ctrl + Z**
2. 恢复：输入 `fg` 回车

## 步骤 8：凭证过期 / 报错处理

### 8.1 `invalid session` / `API Error: ret 200003`

表示 **token/cookie 过期**，与 fakeid 无关：

```bash
./pipeline.sh sync-session
./pipeline.sh bootstrap   # 或 daily
```

### 8.2 SSL 报错 `SSLEOFError`

```bash
source AIAgent_algorithm/bin/activate
pip install "urllib3>=1.26.18,<2"
python -c "import urllib3; print(urllib3.__version__)"
```

### 8.3 强制重下某篇文章

```bash
rm "公众号文章/公众号名/2026-05-16_标题.md"
./pipeline.sh daily
```

## 步骤 9：其它辅助命令

### 9.1 查看 pipeline 帮助 / 输出路径

```bash
./pipeline.sh help
./pipeline.sh paths
```

### 9.2 持续监视模式（旧逻辑，一般不用）

```bash
python wechat_crawler.py.py watch
```

按 `config.json` 中 `check_interval_minutes` 循环检查（默认 60 分钟）。

### 9.3 查看已爬文章数量（需先跑过 bootstrap/daily）

```bash
find 公众号文章 -name "*.md" 2>/dev/null | wc -l
find 公众号文章 -mindepth 1 -maxdepth 1 -type d 2>/dev/null | wc -l
```

## 推荐完整流程（从零到日常）

| 顺序 | 做什么 | 命令 |
|------|--------|------|
| 1 | 环境 | 步骤 1 全部 |
| 2 | 确认清单 | 检查 `gzh.txt`、`公众号名字` |
| 3 | 同步登录 | `./pipeline.sh sync-session` |
| 4 | 首次每号 10 条 | `./pipeline.sh bootstrap` |
| 5 | 安装每天 17:00 监测 | `./pipeline.sh install-cron` |
| 日常 | 凭证过期时 | `./pipeline.sh sync-session` |
| 日常 | 手动补跑增量 | `./pipeline.sh daily` |
